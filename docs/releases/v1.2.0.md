# NodePilot v1.2.0

## 界面与交互

- 新增青蓝、靛紫、翡翠、琥珀、玫红五套配色，均支持深浅模式，选择保存在当前浏览器。
- 调整页面标题、卡片、表格、按钮与响应式布局；概览突出节点地图、流量与待处理事项。
- 节点列表精简区域展示，移除国家 emoji 和地址副标题。
- 订阅列表新增二维码快捷入口。
- 登录卡片移除重复 Logo，顶部品牌支持返回运行概览。
- 增加编辑离开提醒及弹窗关闭提醒，完善忙碌按钮状态。
- 调整地图陆地、网格和节点标记的主题配色。

## 安装包

提供 Linux amd64 / arm64 的 Server 与 Agent 压缩包。Server 包含前端静态资源和规则文件；升级前请备份配置及数据库，并一并更新 web 目录。

## 验证与限制

- Go 测试、前端 JavaScript 语法及差异格式检查通过。
- 浏览器自动化授权不可用，本次未完成逐页截图、全部主题与窄屏的实机验收。
- 列表操作收敛、空/错状态进一步统一仍待后续完善；地图保留现有投影与数据，不是参考项目地图的完整复刻。
