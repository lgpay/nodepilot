# NodePilot v1.2.4

## 渐进式重构与稳定性优化

- 模块化部署、入站与客户端处理逻辑。
- 抽取入站 Service 层，统一协议、传输和 REALITY 配置准备。
- 强类型化 Xray 传输配置，并补充安全层校验。
- 统一部署、通知、探测和证书任务队列，支持优雅停止与任务排空。
- Agent 心跳和流量采集支持优雅关闭。
- 增加客户端 API 集成测试和数据库索引约束。
- 统一旧日志输出到结构化日志处理器。
- 拆分前端入站配置与 UI 辅助模块，增加前端语法检查。
